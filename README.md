# Bài Tập: Tạo Bảng Danh Sách Sản Phẩm (HTML Product Table)

Bài tập thực hành xây dựng bảng danh sách sản phẩm trong HTML5:
- `<table>`: Thẻ bao bọc bảng dữ liệu
- `<tr>`: Các hàng trong bảng
- `<th>`: Tiêu đề các cột (Tên sản phẩm, Giá, Số lượng)
- `<td>`: Dữ liệu chi tiết cho tối thiểu 4 sản phẩm
- CSS cơ bản căn chỉnh border, padding và màu nền dòng tiêu đề.

## 🚀 Cách mở xem
Mở trực tiếp tệp [`index.html`](index.html) bằng trình duyệt web bất kỳ (Chrome, Edge, Firefox,...).
